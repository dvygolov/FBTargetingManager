# FB Targeting Manager

Browser-side tool for account-level Facebook Ads Manager targeting: it lists every ad account, shows where age, geo and placement restrictions are already set, and applies the ones you pick to one or many accounts at once.

## Install

Open https://fbtargetingmanager.pages.dev/ and drag the Targeting button to your bookmarks bar.

## Build

```powershell
npm run build
```

## Deploy

```powershell
npm run deploy
```
